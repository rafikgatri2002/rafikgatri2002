### 🔥 Featured project — IronLog
A full-stack AI fitness tracker I built end to end: mobile app, backend, AI, and deployment.

- **Mobile app** (React Native · Expo · TypeScript): workout & session logging, live
  personal-record detection, progress dashboard, secure JWT auth. Shipped as an Android build.
- **Backend** (FastAPI · MongoDB): clean feature-based architecture, unit-tested, Dockerized,
  CI/CD to Azure that only deploys if tests pass.
- **Agentic AI coach** (Google Gemini, function calling): logs, plans and reschedules
  training from natural language — with a human-in-the-loop confirmation step so no action
  runs until the user approves it.
